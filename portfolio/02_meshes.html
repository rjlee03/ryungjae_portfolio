Project Procedural Geometric Modeling

3D Graphics

Project Overview

This is the second assignment for CS250 Computer Graphics II at DigiPen Institute of Technology. The goal was to write code that procedurally generates six 3D shapes — Plane, Cube, Sphere, Torus, Cylinder, and Cone — purely from math, without loading any model files.

Each shape is built at runtime using parametric equations, with a configurable number of stacks and slices that control how smooth or blocky it looks. The shapes are rendered three ways: textured, wireframe, and with normal vectors drawn so you can see if the lighting math is correct.

Tasks Completed

  • build_index_buffer — Wrote the index buffer generator that connects a grid of vertices into triangles. Each cell of the stacks × slices grid becomes two triangles, and this same buffer is reused by every shape that is built on a grid.
  • create_plane_vertices — Generated a flat plane centered at the origin with positions in the XY plane, normals pointing in the +Z direction, and UV coordinates mapped from (0,0) to (1,1) across the surface.
  • create_sphere — Used spherical coordinates (beta for latitude, alpha for longitude) to place each vertex on the surface of a sphere. Normals are just the normalized position vector since every point faces outward from the center.
  • create_torus — Built a torus using a major radius of 0.35 and minor radius of 0.15. The normal at each vertex is computed by pointing away from the nearest point on the torus's center ring.
  • add_cap — Wrote a helper that adds a triangle fan to close the top or bottom of a cylinder or cone. Getting the winding order right depending on which end the cap is on was a key detail here.
  • create_cylinder — Generated the side of the cylinder with outward-facing normals, then called add_cap for both the top and bottom to close it off.
  • create_cone — Built the cone with a radius that tapers from the base to the tip. The normals are calculated using the tangent direction so the shading looks smooth rather than faceted.
  • convert_to_lines_pattern — Converted the triangle index buffer into a line index buffer for wireframe rendering by pairing up the edges of each triangle.

Reflection

The torus was by far the hardest shape to implement. I understood the basic idea — sweep a circle around an axis — but figuring out the correct normal calculation took a while. You have to find the center point on the inner ring and point away from it, which is not obvious at first. Once I saw it working with the normal visualization turned on, it clicked.

I also learned that the index buffer pattern for the grid is surprisingly flexible. I wrote it once and it worked for the plane, sphere, torus, and the body of the cylinder and cone without any changes. The caps were a separate challenge since they need a triangle fan layout instead of a grid, which is a completely different index pattern. Overall this assignment gave me a much clearer picture of how 3D geometry is actually stored and sent to the GPU.
